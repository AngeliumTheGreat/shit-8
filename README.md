# shit8

shit8 is a chip8 emulator that sucks

its dependencies are lua5.4 and luasystem

## features:

- display right to your terminal!
- beeps! (actually bell characters)
- key input! (that's delayed and bad)
- passes most chip8 tests! yay!

## usage:

don't. but if you must...

- download main.lua
- run it with lua 5.4! like this: `lua main.lua [options] <filename>`

options? yes. run `lua main.lua --help` to read about them
